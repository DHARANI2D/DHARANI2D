I build autonomous, evidence-backed security systems — from SOC detection engines to AI agent runtime security — and I'm applying to MSc programs in Advanced Computer Science / Cybersecurity for Fall 2027.

## 💼 Experience

**Cybersecurity Analyst** — Hewlett Packard Enterprise · *Sep 2025 – Present*
Monitor enterprise-scale threats and triage 100+ daily alerts across endpoint, cloud, identity, and email systems. Own the full incident lifecycle — detection, triage, containment, eradication, remediation — with root cause analysis for phishing, malware, account compromise, and lateral movement. Map threats to MITRE ATT&CK, tune SIEM correlation rules, and build Python automation for AI-driven anomaly detection and alert prioritization. Remediate AWS/Azure cloud misconfigurations and implement IAM controls (RBAC, MFA, zero trust).

**Cybersecurity Analyst Intern** — Hewlett Packard Enterprise · *Feb 2025 – Aug 2025*
Monitored SIEM and endpoint alerts, supported phishing/malware triage using Splunk and CrowdStrike, and contributed to incident response playbooks with hands-on exposure to Wiz and Azure cloud security tooling.
